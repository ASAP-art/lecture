# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Static HTML, CSS, and JavaScript deployed under GitHub Pages at `/lecture/new-site/`.

## Users

Students and office workers who need one place to review tasks, manage schedules, and write a personal diary.

## Product Purpose

Make it easy to see current work at a glance, add and edit dated tasks, and keep diary entries in the same focused workspace.

## Positioning

A private, browser-local daily desk that pairs an actionable schedule with reflective diary writing without requiring an account or backend.

## Operating Context

Users check the site throughout the day on desktop or mobile, update task status, adjust schedules, and write a diary entry for a selected date.

## Capabilities and Constraints

- Add, edit, complete, and delete scheduled tasks.
- Show pending work at a glance.
- Create and edit diary entries by date.
- Persist data in the current browser with site-specific localStorage keys.
- Keep every implementation file inside `new-site/`.
- Do not modify, move, or delete the repository root `index.html`.
- GitHub Pages must continue serving the existing site at `/lecture/` and this site at `/lecture/new-site/`.
- No login, server database, or cross-device synchronization.

## Evidence on Hand

No external brand assets, claims, testimonials, or imagery were provided. Do not fabricate them.

## Product Principles

- Today’s obligations must be legible within seconds.
- Editing must be direct and reversible.
- Reflection should feel private and calm rather than gamified.
- Browser-local storage behavior must be transparent.
- Task management and diary writing must remain distinct but connected by date.

## Accessibility & Inclusion

Support keyboard operation, visible focus, semantic form labels, readable contrast, reduced motion, and responsive use from mobile through desktop.
