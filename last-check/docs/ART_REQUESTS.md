# 향후 인물 이미지 요청 — 미제공·미생성

현재 사용 가능한 인물 그림은 한이경·박도현·정지후·최은서·오준석·배수현의 **중립 알파 초상 6종뿐**이다. 아래는 향후 별도 제공을 요청하는 목록이며, 이번 변경에서 생성·다운로드·추가·수신 처리한 그림은 없다. 현재 중립 초상이 아래 표정/동작을 표현한다고 주장하지 않는다.

| 인물 | 향후 요청 표정 | 향후 요청 동작·상황 |
|---|---|---|
| 한이경 | 경계, 지친 침묵 | 면담 중 열쇠를 놓거나 설명하는 자세. 문밖 목소리는 현장 그룹으로 배치하지 않음 |
| 박도현 | 집중, 신중한 확인 | 명부 두 장/기계 이력을 가리키는 분석 자세 (`CH03_S02`, 선택한 `CH07_S01_A/B`) |
| 정지후 | 긴장, 주저함 | 현장 질문에 답하며 시선을 피하는 자세 (`CH03_S02`, `CH03_S02_B`). 녹음의 목소리에는 적용하지 않음 |
| 최은서 | 경계, 절제된 안도 | 문서 위에 손을 올리는 자세 (`CH03_S02_09/10`). 편지 내용을 이미지로 미리 공개하지 않음 |
| 오준석 | 집중, 신중한 설명 | 이력/정의를 확인하며 설명하는 자세 (선택한 `CH07_S01_A/B`) |
| 배수현 | 당혹, 조심스러운 확인 | 명부·태그를 떨어뜨려놓거나 빈 접수 양식을 설명하는 자세 (`CH03_S02_A`, `CH06_S02_B`) |

## 수신 후 연결 기준

- 기존 얼굴·의상·1024×1536 비율과 투명 배경을 유지하고, 얼굴·손이 잘리지 않는 독립 초상으로 제공한다. 새 인물·새 사건·새 장소·문서의 정답 텍스트를 만들지 않는다.
- 실제 제공 파일을 검수·등록한 뒤 `PortraitDirection.assetId`로 연결한다. 선택적 `expression`/`action`은 연출 메타데이터이며 이미지 생성기나 누락 자산의 대체 기능이 아니다.
- 원문의 해당 현장 블록과 실제 선택 경로에서만 지정한다. 기존 before/after·완료 공개·확정 variant·현장 소개·녹음 제외 정책을 그대로 적용한다. 편지/수첩/엔딩 컷의 별도 공개 정책을 앞당기지 않는다.
