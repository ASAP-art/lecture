## 독립 기대값

`tests/fixtures/decision-oracle.ts`는 원문 197–202행, 1927–1940행, 1962–1985행과 확정 C15 계약을 수기로 옮긴 기준이다. 기대값 계산은 실제 JSON의 condition/effect, 엔진의 조건 평가 함수를 재사용하지 않는다. 실제 콘텐츠와 reducer/전이 함수만 검사 대상에 사용한다.

- D1–D6: 각 전제의 모든 참/거짓 조합을 검사한다. C16_A/C17_A/C18_A/C20_A/C23_A는 부족한 자료로도 선택되며 추리 미지급·원문 미완성 결과·동일 수첩 문단을 확인한다.
- 최종 판정: 핵심 증거7개의 128조합 × D1–D5의 32조합 × final_chain/D6/return_agency/restored의 16조합 = 65,536개 입력을 검사했다. restored는 최종 proof의 별도 전제가 아니므로 불필요한 재요구도 검출한다.
- 각 입력에서 C24_A/B/C를 엔진에 직접 보낸다. 금지 입력은 예외로 거부되고 직렬화한 입력 상태 전체가 변하지 않아야 한다.
- 실제 경로로 C11_B의 GOOD, D6 보유/입증 실패 BAD01, C14_B/C→C16_A/B 기회비용, C15의 E04/E07 동시보완 불가를 별도로 확인했다.

## 상태 보존·생략 근거

보존: scene/stage/block/cursor/표시단계, **모든** 증거·추리·flag, 조건에서 읽는 은서 trust의 정확한 값, 현재/향후 장면에서 참조하는 적용 effect ID, 현재 장면의 확정 variant, 현재 선택의 이미 확정 여부. 불필요한 증거/flag도 보수적으로 보존하므로 최소 동치류라고 주장하지 않는다.

| 생략 항목 | 판정·도달성을 바꾸지 않는 근거 |
|---|---|
| 다른 인물 관계·모든 suspicion | entry/choice/block/variant/effect/route/확인 조건을 전부 순회해 읽는 trust 인물을 산출했다. 은서 이외는 조건에 없고 관계 산술은 해당 인물 값만 변경한다. suspicion은 조건 연산 자체에 없다. |
| 더는 쓰이지 않는 적용 효과 | 현재와 모든 미래 장면의 effect 참조 합집합을 정적 그래프로 계산한다. 그 집합에 남은 효과는 키에 보존하며 과거 전용 효과만 생략한다. |
| 과거 선택 이력·과거 variant | 82장면 그래프는 DAG이고 block ID는 고유하다. 과거 장면/블록을 다시 실행하지 않는다. 현재 선택 확정 guard와 현재 장면 variant는 별도 보존한다. |
| 공개 이력·표시 로그 | 실제 블록과 공개 효과는 생략하지 않고 실행한다. 이 필드들은 조건·효과 산술·next의 입력이 아니다. 공개의 선행 증거 검사는 보존된 evidence로 실행된다. |
| runId/parentRunId/revision | 로그·저장 식별자만 바꾸며 조건/판정/next는 읽지 않는다. |
| seed | 선택지 표시 순서만 바꾼다. ID로 모든 허용 선택을 탐색하며 엔진 판정은 seed를 읽지 않는다. |

TITLE은 의도된 **새 실행 화면 명령**이므로 단일 실행의 비의도적 루프 판정에서 제외한다. 재열람 UI·임의 손상 저장 파일·모든 브라우저 렌더 상태를 이 동치류 수로 검증했다고 주장하지 않는다.

## 수정된 경계 불일치

독립 검사가 공통 E06 누락의 C17_A, 공통 E09 누락의 C18_A에서 추리는 미지급인데 완성 대사를 출력하는 2건을 검출했다. 각 결과 variant와 수첩 공개 조건을 D3/D4의 전체 전제에 맞췄다. 원문 문장·출처·ID·추리 지급 규칙은 바꾸지 않았다.

정상 도달 상태의 CH07_S03 동치류 720개 모두 E06을, CH08_S01 동치류 1,120개 모두 E09를 보유했다. 따라서 보강은 공통 자료가 빠진 비정상/격리 입력에만 영향을 주며 정상 경로의 원문 분기는 그대로다.
