# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

React 19, TypeScript 7, Vite 8, Zod, Vitest, Playwright, localStorage. npm lockfile을 기준으로 사용한다.

## Users

한국어 선택형 추리게임을 혼자 읽고 선택하는 플레이어. 데스크톱과 모바일 브라우저를 모두 지원한다.

## Product Purpose

원문 「마지막 확인」의 대사·서술·문서·선택·조건부 결과를 바꾸지 않고 플레이 가능한 결정형 웹게임으로 제공한다. CH01–CH10과 네 엔딩을 연결했으며, 원문 마지막 카드 뒤 종료 문장과 타이틀 복귀를 제공한다. 최종 미술·사람 플레이·배포 완료와는 별개다.

## Positioning

원문에 명시된 증거와 인과관계를 선언형 데이터와 재현 가능한 순수 전이로 실행한다. 선택 결과, 효과, 수첩 공개, 저장 복원이 같은 기록에서 파생되어 렌더링이나 새로고침이 사건 상태를 바꾸지 않는다.

## Operating Context

- 상단 장면 그림, 하단 대사, 그 아래 선택지 순서로 읽는다.
- 블록 완료, 선택, 결과 전이마다 자동 1개 슬롯에 저장한다. 수동 슬롯 3개·지목전 보호본·도달 챕터 입장 전 기록은 별도이며 글자마다 쓰지 않는다.
- 타이핑 중 복원은 같은 블록 처음부터 다시 표시하되 다음 블록으로 건너뛰지 않는다.
- 원문 증거를 논리적으로 획득한 시점과 수첩 제목·내용을 공개하는 시점은 다를 수 있다.
- 완료 원본의 실제 입장 기록에서 새 실행으로 챕터를 분기한다. 수동/보호본 되돌리기도 원본을 보존한 실행이며 이후 자료를 합치지 않는다.
- 설정·엔딩 수집은 수사 저장과 분리한다. 저장 실패·용량 부족·탭 충돌은 메모리 진행을 유지하고 성공으로 표시하지 않는다.

## Capabilities and Constraints

- CH01–CH10과 네 엔딩의 실제 원문을 플레이 가능하게 제공한다.
- 원문 next 순서와 각 선택 효과를 한 번만 적용한다.
- 현재 장면, 허용 선택, 미확정 상태를 엔진이 검사한다.
- 조건부 결과는 효과 적용 전 상태로 한 번 확정하고 저장한다.
- 엔딩은 원문 조건과 확보 자료로 판정하며, 종료 시 미획득 E/D를 소급 지급하지 않는다.
- 자유 AI 심문·재조사, 확률, 추가 퍼즐, 로그인, DB, 결제, 실시간 생성, 서비스워커를 사용하지 않는다.

## Brand Commitments

- 제목은 「마지막 확인」이다.
- 특정 작가나 소설의 문체·인물·장면을 모사하지 않는다.
- 제공 자산 22종만 표시하며 미수신·로딩 실패는 중립 빈 영역으로 남긴다. 실제 장소와 설명 참고컷을 구분하고 참고컷은 새로운 인물·사건의 근거로 사용하지 않는다.

## Product Principles

1. 원문과 상태의 정확성이 연출보다 우선한다.
2. 플레이어가 아직 보지 않은 비밀은 UI와 저장 공개 이력 모두에서 숨긴다.
3. 모든 진행은 결정적이고 복원 가능해야 한다.
4. 구현되지 않은 범위를 완성된 것처럼 보이지 않는다.
5. 기능·미술·사람 플레이·배포 완료를 분리한다.

## Accessibility & Inclusion

키보드 조작·명확한 포커스·44px 이상 버튼·충분한 대비·데스크톱/모바일 반응형을 지원한다. 대사 크기·즉시표시·타이핑 속도·모션 줄이기는 게임 상태와 독립적이며 현재 블록을 기다리지 않고 모두 표시할 수 있다. 모바일 수첩은 별도 패널이고 선택은 고정 높이에 가두지 않는다. 현재 원문 전체를 보조기술에 제공하며 글자별 알림·자동진행·시간제한을 두지 않는다. 음향 없는 버전이다.
