# PART 1. 게임 기획서

## 1. 콘셉트

**제목: 마지막 확인**

“그 시간에 그 사람은 분명히 거기 있었다. 그런데 그것이 무엇을 증명하는가?”

민간 기록복원센터의 구형 이동식 서가에서 센터장이 사망한다. 현장은 수동 조작 상태이고, 관리자의 열쇠에는 최근 사용 흔적이 있다. 가장 의심스러운 아들에게는 빈틈없는 영상 알리바이가 있다. 어머니는 아들을 변호하는 대신 자신의 열쇠와 거짓말을 수사관에게 하나씩 내놓는다.

플레이어는 누가 서가를 움직였는지 찾다가, 누가 ‘그 안에는 아무도 없다’는 판단을 만들어냈는지 조사하게 된다. 살인범과 수사를 설계한 사람은 다르다. 한 사람은 타인의 목숨을, 다른 사람은 타인의 책임까지 자기 뜻대로 처리한다.

- 배경: 2026년 11월의 평일 저녁. 경기 남부의 가상 도시, 사설 기록복원센터 ‘이음기록원’.
- 공간: 지하 수장고, 기계실, 안전실, 경비실, 면담실, 임시 증거분석실.
- 범위: 한 건의 현재 살인사건과 25년 전 아동 기록 위조. 다른 사망자나 시체 바꿔치기는 없다.
- 시점: 강력팀 형사 윤서진의 1인칭. 플레이어에게 알려지지 않은 서진의 기억이나 독백으로 정답을 숨기지 않는다.
- 수사 참여 이유: 서진은 관할 당직 형사다. 사망 신고 뒤 사고·범죄 가능성을 확인하라는 출동 지시를 받고 현장에 온다.
- 목표: 사건 구조의 증명과 당사자의 선택을 어디까지 되돌려줄지 판단하기.
- 표현: 고어 없이 적재대 충돌음, 멈춘 모터, 접힌 서류로 불안을 만든다.

## 4. 인터페이스·실행 규약

- 본문, 인물 초상·이름, 선택지, 증거 수첩, 시간표, 가설판을 둔다.
- 24개의 선택 지점, 총 54개의 개별 선택지를 제공한다. 결과 장면에도 고유 ID를 준다.
- 본문에 적힌 대사는 생략하지 않고 표시한다. 선택 결과 장면을 출력한 다음 지정된 다음 장면으로 이동한다.
- 선택 지점은 한 번만 확정한다. 수첩에서는 기존 대사·증거·시간표를 자유롭게 다시 읽을 수 있지만, 미선택 분기의 증거는 얻지 못한다.
- 각 장면의 `입장`이 `직전 결과`인 경우, 바로 앞에 지정된 결과 장면 중 하나를 통해 들어온다. `자동` 이동도 명시된 링크를 따른다.
- 모든 결과의 `기록 없음`은 기존 증거를 지운다는 뜻이 아니다. 모든 증거는 획득 후 보존한다.
- `T이`, `T지`, `T은`, `T오`, `T배`는 인물별 trust의 약기다. `S`는 suspicion이다. 변동이 없는 변수는 그대로 유지한다.
- trust 범위는 -2~2, suspicion은 0~3으로 제한한다. suspicion은 플레이어의 가설 표시이며 진범 판정을 대신하지 않는다.

```js
state = {
  evidence: new Set(),
  trust: { 이경:0, 지후:0, 은서:0, 준석:0, 수현:0 },
  suspicion: { 이경:0, 지후:0, 은서:0, 준석:0, 수현:0 },
  deductions: new Set(),
  insight: 0,
  flags: {
    envelope:false, early_accuse:false, private_access:false,
    restored:false, return_agency:false, final_chain:false,
    outcome:null
  }
};
// D 획득은 Set.add. insight = deductions.size. 중복 점수 없음.
// 모든 장면·선택 효과는 1회만 적용한다.
```

이 원고에 등장하는 설비와 운용 절차는 사건을 위한 가상 설계다. 현실 설비의 조작 지침으로 사용하지 않는다. 주요 사실은 챕터 2에서 설명하며, 후반에 새로운 기계 기능을 추가하지 않는다.

# PART 2. 사건의 진상 — 개발자 전용

## 1. 고정된 진실

**실제 살인범은 정지후. 수사 기만의 설계자는 한이경이다.**

지후는 태오에게 “당일 마감을 보류하고 원본을 대조하니 A3 안쪽에서 19시 41분까지 기다려 달라”는 확인서를 보냈다. 태오는 자신의 불법 기록이 외부로 나가기 전에 확인하려고 직접 서명하고 들어갔다. 지후는 안전실에서 그 회신을 읽었다. 태오는 마감이 보류된다고 믿었으므로 정상 마감 시각 뒤까지 남기로 했다. 19시 39분 05초에는 A3 고정 내선으로 걸려온 태오의 전화를 받고 계속 기다리라고 답했다. 그곳에서 위험 구역 출구까지는 최소 90초가 걸린다. 그러므로 25초 뒤의 ‘전원 퇴실’ 확인은 단순히 그가 먼저 나갔으리라는 믿음으로 설명할 수 없다. 19시 40분 예약 마감 때 서가가 이동했고 태오가 사망했다.

지후는 기계에 접속하거나 스위치를 만지지 않았다. 장치를 직접 작동시키는 명령도 보내지 않았다. 정상적인 예약 마감에 필요한 **사람에 관한 확인**을 고의로 거짓 작성했다. 범행 시각을 바꾸는 트릭이 아니다. 19시 40분의 사고 사건, 같은 피해자, 같은 장소가 모든 분기에서 유지된다.

이경은 지후의 안전 확인과 자신이 받은 대조 확인서 사본을 대조해 아들의 행위를 알아챘다. 경비실에 남는 자동 이력의 존재도 알고 있었다. 그녀는 사고를 미리 예측하지 않았다. 사건 이후 약 20분 동안 자신에게 모이는 사실을 이용해 거짓 수사 경로를 만들었다.

19시 46분 기계실에서 정지된 선택 스위치를 HAND 쪽으로 옮기고 외함에 새 긁힘을 남겼다. 장치를 재가동하지는 않았다. 열쇠 사용, 관리책임자 이름, 태오와의 금전 관계, 자신의 자백을 연결하면 ‘관리자가 수동으로 강제로 서가를 움직였다’는 이야기가 생긴다. 이경은 지후의 알리바이 확인을 적극 돕고 자신에 대한 의심도 막지 않는다.

## 2. 장치·자료의 의미 — 처음부터 고정

1. 구형 이동식 서가는 매일 19시 40분 예약 마감을 한다. 구형이라 안쪽 사각지대의 사람을 감지하지 못한다. 준석은 수동 대조 절차와 개선 요구를 남겼지만 원장이 비용을 이유로 거부했다. 이 위험 자체도 조사 대상이다.
2. 예약 마감은 안전실의 인원 확인서를 경비가 접수하고 운용 단계에 반영한 경우에만 진행된다. 준석은 현장 밖에서 마감을 감시한다. 확인서는 안전상의 핵심 자료이며, 단순한 참고 메모가 아니다.
3. 별도의 서비스 열쇠를 사용하면 현장에서 수동 운전이 가능하다. 이경과 준석에게 권한이 있다. 구체적인 조작 순서는 게임에 제공하지 않는다.
4. 화면의 ‘관리자: 한이경’은 장비에 등록된 관리책임자다. 회차별 조작자를 인증하는 값이 아니다.
5. 화면 현재값 HAND는 열람 시점의 위치다. 19시 40분 상태를 소급 증명하지 않는다.
6. 독립 기록기는 실제 이동 신호와 선택 상태 변경을 별도로 기록한다. 사람이 읽는 요약 화면과 별개이며, 경비실 봉인 출력물에도 같은 사건번호가 남는다.
7. 경비의 ‘접수’ 도장은 서류를 받았다는 뜻이다. 안전실이 작성한 인원 확인의 진실성까지 경비가 확인했다는 뜻이 아니다.
8. 현재 사건의 핵심 원본은 경찰이 모두 보전한다. 플레이어가 놓친 자료는 훼손되거나 사라지는 대신, 초동 분석·최종 제출에서 빠진다. 잘못된 엔딩은 진실이 변한 세계가 아니라 분석이 잘못된 세계다.

## 3. 완벽한 알리바이의 실제 범위

지후는 19시 30~45분 안전실 안에 계속 있었다. 고정 카메라 원본, 경비와 은서의 왕래, 화면 속 실시간 응답, 출입기록이 일치한다. 대역·편집·시간 변경은 없다. 안전실에는 모터 원격 조작 기능이 없고, 이동 거리는 왕복 최소 7분이다.

따라서 **지후가 19시 40분 현장의 수동 스위치를 직접 조작했다**는 가설은 거짓이다. 그러나 **지후가 죽음에 필요한 거짓 안전 확인을 했다**는 가설과 알리바이는 완전히 양립한다. 오히려 그가 안전실의 작성자였다는 점을 더 강하게 입증한다.

범행을 논리적으로 증명하려면 다음 네 가지를 모두 구분해야 한다.

| 질문 | 실제 답 |
|---|---|
| 누가 현장 스위치를 만졌나? | 이경. 19:37 점검과 19:46 사후 변경. |
| 무엇이 19:40 이동을 발생시켰나? | 정규 예약 마감. |
| 그 마감을 가능하게 한 핵심 거짓은 무엇인가? | 지후의 ‘대상자 4명 전원 퇴실’ 확인. |
| 지후는 누군가 남아 있음을 알았나? | 본인이 보낸 대기 지시의 서명 회신을 읽고, 태오의 잔류를 특정한 재확인 질문에도 비었다고 답했다. |

## 4. 기만 설계와 한계

- 이경은 진짜 열쇠와 진짜 사용 사실을 내놓는다. ‘지후는 기계실에 오지 않았다’도 사실이다.
- 화면과 현재 스위치를 앞세워 수사를 ‘현장의 직접 조작자 찾기’로 좁힌다.
- ‘안전실에는 네 명이 있었다’는 참인 문장과 ‘수장고 대상자 네 명이 모두 나왔다’는 거짓 문장을 비슷하게 들리게 만든다. 안전실 네 명은 지후·이경·은서·준석이고, 확인 대상 네 명은 태오·이경·은서·준석이다.
- 지후가 말하는 진실은 알리바이다. 지후가 말하는 거짓은 잔류자 확인이다. 이경은 두 문제를 연결하지 않게 유도한다.
- 자신의 수동 조작 자백은 거짓이다. 이후 ‘출력물은 자동도 기록한다’, ‘열쇠를 썼다’ 등의 사실로 거짓을 지탱한다.
- 그녀의 약점은 독립 기록기다. 19:40 예약 이동과 19:46 HAND 변경의 순서를 바꿀 수 없다. 출력물은 경비실에 있고 그녀에게 단독 접근권이 없다. 없앨 수 없으므로 중요도를 낮추고 다른 해석을 권한다.
- 그녀는 수사관이 반드시 속는다고 예측하지 않는다. 기록기를 확인하면 실패할 것을 알고, 자신의 자백과 강한 동기가 그 확인을 밀어내기를 기대한다. 실패하면 지후를 협박하거나 증거를 파괴하는 두 번째 계획은 없다.
- 지후는 완전범죄의 천재가 아니다. 사전 확인 절차를 악용한 살인범이며, 초동 수사가 직접 조작으로 좁혀질 것에 기대었다. 이경의 은폐는 지후가 의뢰하거나 사전에 합의한 것이 아니다.

## 5. 동기와 두 번째 반전

태오는 옛 시설 기록을 이용해 이경을 오래 협박했다. 이경은 25년 전, 입원 중인 지후의 친모가 양육을 포기한 것처럼 서류를 위조했다. 그 서류를 근거로 지후를 자기 아들로 데려왔다. ‘구조’라고 자신에게 말했지만, 지후와 친모의 선택을 빼앗은 행위였다. 태오도 이 기록 은폐에 관여했다.

지후는 태오가 친모의 기록을 수익 수단으로 쓰고 원본을 폐기하려는 것을 알았다. 원본 일부는 이미 은서에게 전달돼 있었다. 따라서 살인은 자료를 지킬 유일한 방법이 아니었다. 지후는 태오를 더는 자기 삶을 결정할 수 없는 사람으로 만들고 싶었다. 그 분노와 통제욕 때문에 죽음을 선택했다. 게임은 이를 구출 행위로 미화하지 않는다.

첫 해석에서 이경의 희생은 ‘아들이 엄마를 지키려 저지른 범행에 보답하는 모성’처럼 보인다. **그러나 지후는 이미 사흘 전에 이경의 과거 행위를 증언하겠다고 결정했다. 당일 17시 10분 이경은 그 글을 읽었다.** 그녀가 지후를 보호해도 아들은 돌아오지 않을 것이며, 오히려 그녀를 고발할 예정임을 알고 있었다.

그녀는 옛 위조 사실을 덮으려고 현재 살인까지 떠안는 것이 아니다. 은서에게 원본을 넘겨 **자기 과거도 드러내고, 현재 살인의 책임만 아들에게서 가져오려 한다.** 기록을 고치는 일을 평생 해왔으나, 끝내 아들의 선택까지 자기 손으로 고치려 한다는 역설이다.

TRUE에서는 지후가 “내가 증언하는 건 내 선택이고, 내가 죽인 것도 내 책임이에요”라고 말한다. 이경의 헌신은 진심이지만 또 한 번의 침해다. 두 사람이 서로 용서하거나 가족으로 복귀하는 결말은 보장하지 않는다.

## 읽는 법

각 선택의 결과 장면에 `기록`, `변경`, `다음`을 적었다. 선택하지 않은 결과 장면은 표시하지 않는다. 공통 본문에 있는 증거는 공통 효과로 획득한다. 선택의 ‘정답’ 표시는 개발자용 판정에만 두고 플레이 UI에서는 숨긴다. 등장하지 않은 인물의 속마음은 서술하지 않는다.

## 2. 엔딩 판정 코드

```js
const hasAll = (set, ids) => ids.every(id => set.has(id));
const proof = s => s.flags.final_chain &&
  hasAll(s.deductions, ['D1','D2','D3','D4','D5']) &&
  hasAll(s.evidence, ['E03','E04','E05','E06','E07','E09','E10']);
const full = s => proof(s) && s.deductions.has('D6') &&
  s.flags.return_agency;

function endingFor(s, choice) {
  if (choice === 'C24_A')
    return full(s) ? 'END_TRUE' : proof(s) ? 'END_GOOD' : 'END_BAD01';
  if (choice === 'C24_B') {
    if (s.evidence.has('E07') || s.deductions.has('D3'))
      throw new Error('Disabled choice: incompatible evidence');
    return 'END_BAD02';
  }
  if (choice === 'C24_C') {
    if (proof(s)) throw new Error('Disabled choice: proof already established');
    return 'END_BAD01';
  }
  throw new Error('Unknown choice');
}
```

판정 코드는 개발자 전용이다. 플레이어에게는 `proof`, `full`, 점수, 정답 증거 목록을 노출하지 않는다. 대신 보드에 실제 확보·미확인 구분만 보여준다. 최종 지목 전에 자동 저장하고, 엔딩 후 챕터 선택은 새 분기 저장으로 처리한다. 같은 실행에서 다른 선택의 증거를 합산하지 않는다.

선택지 ID와 화면 순서는 분리한다. 문서의 A/B/C는 참조용이다. 실제 게임에서는 저장 파일의 고정 seed로 선택지 표시 순서만 섞고, 플레이어에게 ID는 보여주지 않는다. 증거·성공 판정에는 난수를 사용하지 않는다. 정답의 문서상 위치를 반복 클릭하는 공략을 방지하기 위한 표시 규칙이다.

## 구현 전에 지킬 다섯 가지

1. 대기 지시·안전 확인·실제 작동은 각기 다른 자료다. 하나를 얻었다고 나머지 전문을 미리 보여주지 않는다.
2. BAD02에서 원본이 파괴됐다고 바꾸지 않는다. 보완 분석으로 오류를 알아채는 결말이므로 최초의 기만과 이후의 수정이 함께 성립한다.
3. TRUE의 가족 비밀은 살인 증거의 대체물이 아니다. 개인 면담을 놓쳐도 GOOD이 가능해야 한다.
4. 지후의 살인은 이경의 지시가 아니다. 이경의 사후 은폐도 지후와의 합의가 아니다. 두 사람은 별개의 행위자다.
5. 원본을 모두 획득한 플레이어에게 ‘증거가 없어서 이경을 유죄로 확정’하는 장면을 강제하지 않는다. 부정확한 가설은 선택 조건과 제출 검증에서 막는다.
